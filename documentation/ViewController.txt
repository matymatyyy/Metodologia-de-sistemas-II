ViewController

El view controller se encarga de obtener el path de la vista en particular que lo piense usar.

Su funcionamiento es el siguiente: 
    1- Define el path en comun de todas las vistas, en este caso, la carpeta views.
        private const string BASE_PATH = "%s/src/Views/%s.php";

    2- En el construct, espera que se le pase la ubicacion de la vista especifica respecto a la carpeta Views.
        En el ViewController:
            public function __construct(
		        private string $view
	        ) {
	        }
        Ejemplo de su uso en CarreraViewController.php:	
            public function __construct(){
                parent::__construct("Admin/carreras");
            }

    3- Finalmente, se hace uso de la funcion privada "getBasePath()" a traves de la funcion publica "call(mixed $data)".
       Esta funcion(getBasePath), se encarga de concatenar tres parametros.
        Primero, llama a la constante BASE_PATH definida en el primer punto.
        Segundo, hacemos uso de la supervariable global $_SERVER para obtener el path absoluto del servidor.
        Tercero, obtenemos la $view que nos pasaron desde el construct.
         En el ViewController:
            public function call(mixed $data): void
	        {
		        include_once $this->getBasePath();
	        }

	        private function getBasePath(): string
	        {
		        return sprintf(
			        self::BASE_PATH,
			        $_SERVER["DOCUMENT_ROOT"],
			        $this->view
		        );
	        }
         Ejemplo de su uso en CarreraViewController.php:
            public function start(): void{
                parent::call(""); //El call() recibe "" para no pasar datos adicionales a la vista
            }

MUY IMPORTANTE!!
Para hacer uso del ViewController, es muy necesario incluirlo haciendo uso de la supervariable $_SERVER, ya que no utiliza namespace. 
Luego de eso, es necesario EXTENDER de ViewController para poder hacer uso de "parent".
 Ejemplo de su uso en CarreraViewController.php:	
    include_once $_SERVER["DOCUMENT_ROOT"].'/src/Controller/ViewController.php';
    final readonly class CarreraViewController extends ViewController {}
